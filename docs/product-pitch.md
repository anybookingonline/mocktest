## 30-second pitch (bolkar sunane ke liye)

"Aapke students roz 2 ghante self-study karte hain — bina teacher, bina feedback.
Aisepadho me har student ka apna AI tutor hai: doubt poochho to turant samjhata hai,
galat kiya to solution samjha ke wahi topic fir se practice karata hai, weak topics
apne aap pakad leta hai, aur revision ka roz ka plan deta hai.

Sirf test nahi — battles (1v1 quiz), group study, Telegram par tutor, roz Current
Affairs, All-India ranking aur points/levels. Poora gamified.

School/coaching ke liye: aap apne papers upload karo, humara AI saare questions
nikaal leta hai, aur students ko aapke brand ke app me sab kuch milta hai.
Parents ko ready-made progress report.

Testbook ₹749 me sirf test deta hai. Hum ₹999 me teacher deta hoon."

## Kya-kya hai app me (full feature list)

### Core learning (free plan me bhi)
| Feature | Kya karta hai |
|---|---|
| Practice | Chapter/topic-wise questions, har answer ke baad instant solution |
| Mock Tests | Real exam feel — timer, negative marking, pace dashboard (time-per-question live adjust) |
| PYQ Papers | Saare major exams ke previous year papers — admin PDF upload karta hai, AI khud nikaal leta hai (scanned bhi chalega) |
| AI Doubts | Koi bhi doubt poocho — instant explanation, question se linked bhi (free: 15/day, live counter dikhta hai) |
| Adaptive Practice | Difficulty auto-adjust hoti hai student ke level se; weak topics apne aap zyada aate hain |
| AI Revision | Galat kiye topics 1-3-7-14-30 din ke cycle me wapas — roz ka ready plan |
| Analytics | Chapter-wise accuracy, weak topics, score trends, rank prediction |
| Current Affairs | Roz 10 AI MCQ asli news se (exam-specific) |

### Engagement & social layer
| Feature | Kya karta hai |
|---|---|
| 1v1 Quiz Battles | Doston se ELO duel, speed bonus, 30-sec rounds, leaderboard |
| Group Study | Squad banao, join-code se bulao, group discussion chat (2 paid → 1 dost free) |
| Points & Levels | Har action par points — Newbie se Legend tak, badges, profile recognition |
| Rankings | All-India Rank (percentile), exam-wise leaderboard, ELO ladder |
| Telegram Tutor | Doubts, revision reminders, welcome — sab Telegram par, app kholne ki zaroorat nahi |
| PWA App | Browser se ek-tap install, home-screen icon, offline-ready shell |

### B2B — School/Coaching (white-label)
| Feature | Kya karta hai |
|---|---|
| Apna brand | School ka logo/naam/colors — students ko school ka hi app dikhta hai, subdomain support |
| Apne papers | Teacher PDF upload karo → AI extraction → review → students ke bank me (institute-private, kisi aur ko leak nahi) |
| Students onboard | Invite link ya bulk CSV — poori class ek click me |
| API Access | School ke ERP ke liye API key (students bulk-create, PDF upload — programmatic) |
| Parent Reports | Har student ki progress report print/WhatsApp-ready |
| Quota Control | Per-institute daily AI budget — school owner ka control, aapka loss-guard |
| Teacher AI (Guru Studio) | Teach Kit (topic-wise lesson plans), Classroom Live Quiz (Kahoot-style PIN join), Confusion Check polls, Soft-skills (GD simulator, speech feedback) |

## Demo kaise chalao (5-minute flow)

1. Landing page → sign-up (30 sec)
2. Dashboard → practice kholo → 1 question galat karo → **AI tutor solution** dikhao
3. Doubts page → live counter dikhao → 1 doubt poocho → instant answer
4. Battles → quick-match → jeeto → points badhte dikhao
5. Telegram → bot ko bhejo doubt → reply aata dikhao
6. School walo ke liye: white-label demo + PDF upload → extraction → review queue
7. Pricing: "₹999 saal bhar ka — promo me ₹499, sirf pehle 500 log"
